## summary

bernstein now includes a FastAPI and React web interface shipped directly in the wheel. the cli and tui remain unchanged, with no disruption to existing configurations or workflows. the web ui is intentionally minimal, with no new frontend dependencies beyond the core stack. existing agents, adapters, and task logic continue to function without modification.

## key takeaways

- bernstein now includes a FastAPI and React web interface accessible at http://127.0.0.1:8052/ui/.
- the cli, configs, and agent workflows remain unchanged and fully compatible.
