## summary

this post covers the four things a security architect or procurement reviewer asks before approving an on-prem bernstein deployment. cluster mode can now run worker-central traffic over opt-in mTLS, with a local CA and node certs issued from it, and a two-process test harness covering six chaos scenarios (worker SIGKILL, central restart with in-flight claims, network partition, token expiry, two workers racing, cert revocation). every agent write now emits a signed lineage record linking output bytes to their inputs, producing agent, prompt SHA, cost, and token count, chained via HMAC; `bernstein lineage <file>:<line>` returns provenance six months later. `bernstein wheelhouse build` produces a self-contained wheelhouse directory with pinned wheels and a cosign- or GPG-signed manifest for air-gapped installs; `--profile airgap` puts the orchestrator into explicit egress-deny mode. a capability gate blocks any agent whose tool belt combines `PRIVATE_DATA`, `UNTRUSTED_INPUT`, and `EXTERNAL_COMM` - the lethal-trifecta exfiltration class - before any prompt runs.

## key takeaways

- cluster mTLS is opt-in and uses a private CA with cert rotation; the central trusts any cert with a valid chain to the cluster CA - no shared symmetric secret.
- lineage records include an operator-supplied `regulatory_class` label (recommended vocabulary: `production_detection_rule`, `policy_edit`, `remediation_playbook`, `automated_response`, `posture_query`, `internal_research`) and a customer-key ed25519 signature alongside the cluster-key signature, designed for DORA/NIS2 evidence packages.
- `doctor airgap` runs eight self-checks and returns a single pass/fail line suitable for a procurement runbook.
- FIPS-140 hardware keys, MESH/HIERARCHICAL cluster topologies, and multi-tenant isolation inside a single cluster are explicitly named as not yet done - deferred to 1.11.

## when to read this

for security architects, compliance officers, and procurement reviewers evaluating bernstein for deployment inside a regulated or air-gapped environment.
