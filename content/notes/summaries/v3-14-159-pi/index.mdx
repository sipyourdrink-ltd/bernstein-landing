## summary

the plan loader now raises named errors for malformed fields instead of silently applying defaults. five commands were removed and others reorganized to reduce cognitive load and simplify the interface. reference documentation is now enforced in ci to match the live cli, preventing drift. new features include a muse code adapter, agent plugins v1.0.0, offline-verified run receipts, and audit diagnose.

## key takeaways

- the plan loader now raises named errors instead of silently accepting malformed fields.
