## summary

the output-economy suite caps spend at run level and attributes spend to specific tasks, steps, adapters, and models. cost forecasts are now scored with Brier scores to measure guard confidence against actual outcomes, not just asserted. deterministic orchestration is hardened end to end, with byte-identical replays verified by hash and an unbroken HMAC-chained audit log. the windows adapter path now resolves the agent binary to its absolute path, routes .cmd and .bat shims through the command interpreter, and passes PATHEXT through the worker environment.

## key takeaways

- the output-economy suite caps spend at run level and attributes it with a line-item ledger.
- a windows adapter path bug is fixed: .cmd and .bat agent shims now spawn correctly.
