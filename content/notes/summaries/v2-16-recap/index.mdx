## summary

the output-economy suite enforces per-task token budgets and attributes spend to specific tasks, steps, adapters, and models. cost forecasts are now scored with Brier scores to measure guard confidence against actual outcomes, not just asserted. deterministic orchestration is hardened end to end, with byte-identical replays verified by hash and an unbroken HMAC-chained audit log. the windows adapter path now correctly resolves executables with .exe, .cmd, or .bat extensions and fails with structured errors instead of silently.

## key takeaways

- the output-economy suite now enforces per-task token budgets and attributes spend with a line-item ledger.
- a long-standing windows adapter path bug is fixed, replacing silent failures with clear errors and proper binary resolution.
