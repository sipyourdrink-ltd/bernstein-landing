## summary

this is the hands-on quickstart for bernstein: `pip install bernstein`, point it at Claude Code (or any of the 18 auto-detected adapters), run `bernstein run --goal "<task>"`, and read the TUI that shows task status, agent count, and a live cost ticker. goals get decomposed into tasks, each task gets a role and a model, agents spawn into isolated worktrees, and completed work merges back through the queue. failed tasks roll back into `.sdd/dead_letter.json`. the post also shows the `bernstein cost` output and explains YAML plan files for multi-stage projects.

## key takeaways

- `bernstein run --goal "Add type hints to all functions in src/utils.py"` produces one commit per agent, all merged through the same queue.
- the TUI symbols: `✓` = merged, `►` = running, `○` = pending; `q` is a graceful stop, `Ctrl+C` is a hard stop.
- the task server runs on port 8052 while a session is live, so it can be scripted against.
- `bernstein cost` shows per-session and per-model spend; in the example a 3-task run costs $0.47 split across haiku, sonnet, and opus.

## when to read this

for developers installing bernstein for the first time who want to go from `pip install` to a working multi-agent session in under five minutes.
