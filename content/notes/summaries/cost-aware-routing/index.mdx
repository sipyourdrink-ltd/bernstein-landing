## summary

Bernstein uses a static cascade by default. An optional LinUCB contextual bandit selects a model from task features, while a separate UCB1 bandit selects effort. Capability floors enforce task minimums. During cold start, fewer than 50 completions by default, learned routing delegates to static heuristics. The dated article describes an earlier epsilon-greedy implementation; its performance figures are not measurements of the current router.

## key takeaways

- `BERNSTEIN_ROUTING=bandit` enables learned routing; `bandit-shadow` records its choice while static routing executes.
- Reward combines quality with normalized cost.
- Policy state persists under `.sdd/routing/`.
- `bernstein cost` shows recorded spend for a run.

## when to read this

For operators checking how a task receives its model and effort level.
