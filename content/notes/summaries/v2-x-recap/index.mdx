## summary

bernstein 2.x consolidates thirteen point releases since the 1.10 recap into nine themes. The audit chain became a per-artefact transparency log with Ed25519 signatures, layered onto tracker state moves, and shipped a standalone bernstein-verify wheel an auditor runs without installing bernstein. Ten tracker adapters land under one `TrackerContract` covering Jira, GitLab Issues, Linear, Plane, Asana, ServiceNow, ClickUp, GitHub Projects v2, and webhook ingestion; tracker comments became the orchestration handoff bus so sessions resume across CLI restarts and across operator machines. A2A capability cards close the multi-host handshake gap; the MCP client treats every upstream as untrusted. A web UI plus PWA ships in the wheel, and `bernstein desktop-register` binds the orchestrator into Claude Desktop, Claude Code, Cursor, Continue, Cline, Zed, and Aider with one command. Auto-heal v2 grew teeth (bot-PR class eliminated, Andon gate, hotfix R-counter). Cost guards are calibrated with Brier-scored forecasts plus per-quota-envelope attribution. A secrets broker mints short-lived per-task tokens; supply-chain coverage adds OSSF Scorecard, SBOM, 163 zizmor findings resolved, and a Playwright sandbox for UI agents. The shipped package no longer defaults to the maintainer's private observability endpoints.

## key takeaways

- Two agents writing the same file no longer race silently; the chain reads back, line by line, who edited what and what they had signed for.
- A non-GitHub backlog is not a special case anymore; ten adapters share the same conformance suite that has been keeping the CLI adapters honest.
- `bernstein gui serve --tunnel` is one command for a public URL, a QR, an installable PWA, and a diceware-passphrase login.
- The compliance pack is a single ZIP an auditor can verify with `bernstein-verify` (its own wheel) without trusting the orchestrator to run.
- Cost decisions are read-back instead of inferred: criterion profile, TOPSIS routing, Brier-scored forecasts, per-quota-envelope attribution.
- The MCP client treats every upstream as untrusted, which is the posture the larger ecosystem will end up needing.

## when to read this

For operators evaluating compliance-grade audit chains for the EU AI Act, multi-tracker setups beyond GitHub, the desktop-register binding into Claude Code or Cursor, A2A or MCP hardening posture, or how cost calibration lands in practice on a multi-model cascade.
