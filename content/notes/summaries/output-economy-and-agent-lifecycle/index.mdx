## summary

per-role response-style profiles let operators define output verbosity and tie it to cost attribution. cost ledgers now attribute spend by response profile, enabling direct comparison of verbose versus terse roles. proactive context compaction with chained receipts ensures safe, verifiable memory management during long tasks. team manifests with sha256 pins and drift detection guarantee byte-identical fleet configurations across runs.

## key takeaways

- per-role output profiles and cost attribution let you shape spend by verbosity and role.
- schema-enforced completions, compaction receipts, and pinned manifests make fleets reproducible and auditable.
